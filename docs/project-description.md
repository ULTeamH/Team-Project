# CampusEvents — Project Description

## 1. Overview

CampusEvents is a web application designed to simplify the discovery, organization, and management of university events. It provides a centralized platform where students can browse upcoming events, view details such as dates, times, locations, and descriptions, and register to participate.

Event organizers can create, edit, and manage events, set participant limits, and monitor registrations. Students can view the events they have registered for, while organizers can track registrations and manage attendance.

The application will also provide basic analytical features to help organizers understand student engagement. These may include event popularity, registration trends, attendance comparisons, and statistical reports.

## 2. Main goals

- Make university events easier for students to discover.
- Provide a simple event registration process.
- Help organizers manage events and participant limits.
- Provide useful statistics about registrations and attendance.
- Improve communication between students and event organizers.

## 3. Main user groups

### Students
- Browse and search events.
- View event details.
- Register for events.
- View their registrations.

### Event organizers
- Create, edit, and manage events.
- Set participant limits.
- View registered participants.
- Track attendance and event statistics.

### Administrators
- Manage platform content and users.
- Oversee events and registrations.

## 4. Planned analytics

The Python analytics component may support:

- Event popularity analysis.
- Registration trend analysis.
- Registration-versus-attendance comparisons.
- Organizer reports.
- Simple event recommendations based on student interests and previous registrations.

These are planned features, not part of the initial setup sprint.
