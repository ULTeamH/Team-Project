# Frontend

The frontend will be built with Next.js and TypeScript.

## Initialize the application

From the repository root, run:

```bash
npx create-next-app@latest frontend --typescript --eslint --app --src-dir
```

Choose the team's agreed options in the setup prompts. Then start the development server:

```bash
cd frontend
npm run dev
```

Open `http://localhost:3000`.

The frontend developer(s) should coordinate before initializing this folder so that only one initial Next.js project is created.
