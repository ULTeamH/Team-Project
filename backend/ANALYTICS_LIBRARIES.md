# Python Libraries for Event Analytics

## 1. Pandas

Pandas is a Python library used to organize, manage, and analyze data in tables.

In CampusEvents, it could help with analyzing event registrations and tracking registration trends over time.

## 2. NumPy

NumPy is a Python library used for numerical calculations and working with arrays of numbers.

In CampusEvents, it could help with calculating average attendance and performing basic statistical calculations.

## 3. Matplotlib

Matplotlib is a Python library used to create charts and graphs from data.

In CampusEvents, it could help with showing the most popular events and comparing attendance across different events.
